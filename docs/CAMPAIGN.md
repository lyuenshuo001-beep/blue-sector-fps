# 绝境行动：隔离区线性战役（2.2）

2026-10-04。在稳定版基础上升级；回退标签 `twinkle-ops-pre-campaign`，开发分支 `feature/linear-campaign`。

## 进入与操作

原网址 → 开始游戏 → 绝境行动 → 选择自己的干员和 AI 队友 → 配装 → START。M249 继续免费解锁。旧武器、Credits 和配件存档保留。

十个目标依次推进：安全屋出发 → 废弃街区 → 医院二楼 → 屋顶通道 → 地下停车场 → 启动发电机 → 坚守 60 秒开启防爆门 → 取回实验样本 → 停电收容区门禁 → TITAN → 最终平台坚守 75 秒撤离。

关卡纵向约 300 米；测试沿可走路线完成约 528 米。楼面从地面升至 +4 米，再下降至 -5 米，最后返回地面。医院有隔间与病床，停车场有车辆和车位，实验室有设备台，屋顶和终点有开放天空。采用分离的高处／地下路径，并非重叠多层自由沙盒。移动计时加上守点与战斗，一局通常需要数分钟，尚未进行真人难度校准。

- OBJECTIVE 显示目标与距离，箭头指向导航路径的下一路口；目标区域有高亮地面环。到达后显示 STAND HERE、交互或守点剩余时间。
- 启动设备：靠近后按住 F／触屏交互。离开区域不积累守点时间；松开设备交互会重置当前操作。
- 队友倒地：45 秒救援窗口，靠近 2.6 米内按住 F／救援键 4 秒；复活至 45 HP。超时阵亡。普通火力、随机失误、约 30 秒支援技能，玩家仍是主要战斗力。
- 扑倒：连按 F／Space 或手机 TAP 五次挣脱。
- 低掩体：面向可翻越障碍按 Jump／Space，进行约半秒的自动翻越；高墙与无合法落点处不允许翻越。
- 暂停菜单：继续、设置、重新开始、返回大厅；返回需一次确认，内部切换且不结算未完成任务，不刷新网页。

## 敌人与事件

普通感染者使用制服、长发平民、工装人员三个原创外形；调整脸型、身形、步态与衣着，减少夸张脓包。仍然是轻量程序化风格，非扫描真人模型。

腐液者：飞行毒液和毒区；爆裂者：腹部弱点与连爆；扑袭者：蓄力跳扑和压制；重型：高血量、蓄力砸地／冲撞；疾行者：低血量高速逼近；尖啸者：发现目标后增援并加速附近感染者；潜伏者：远处等待，接近后突进。

TITAN 高度约普通感染者 2.7 倍，进入大厅前有无线电、重脚步／低频提示；具备可见蓄力、砸地范围提示、锁定方向冲撞与击退。侧移可以躲开冲撞，击败后才能完成该阶段。没有声称实现物理破墙、完整抓取动画或布娃娃。

生成结合街区入口和玩家附近的随机导航点，优先视线外／遮挡后，不跨未开启的防爆门生成。48 个固定实体池；LOW/MEDIUM/HIGH 预算 20/30/42。远处普通实体回收；TITAN 不因玩家退远而被删除。

## 手感、手机布局与音频

准心连续收放，体现移动速度、连续射击、蹲姿和 ADS。实际散布也受移动／蹲姿影响。轻微视角起伏与持枪摆动保持原有触屏方式。

设置 → CUSTOMIZE HUD。九个主要按钮可拖动，单独调大小 50%–150%、透明度 20%–100%；布局以屏幕比例保存并避让 safe area。保存后立即应用，下次打开保留。默认布局仍可使用。

枪声由本地噪声、低频冲击、机械层及室内／室外尾音合成；不同类别／型号有参数差异和随机变化，消音器改变音色与音量。是原创合成音，不冒充真实枪械录音。

33 条原创本地 WAV 用于指挥、队友、技能及关键连杀；有优先级、节流、字幕和独立语音音量。语音采用离线 eSpeak NG 合成，机械合成感仍明显，不冒充真人演出。运行时无 TTS API。停电与发电机事件有照明变化，技能加入箭体、吸附物、脉冲网格、电弧、烟尘碎屑和相机反馈。

悬空城保留 A/B/MID 和原有阳台路线，增加东侧建筑内部捷径。经典敌人新增步枪兵、狙击手、重机枪、突击兵、精英，按射程、射速、移动与侧移行为区分；继续使用“路一号”名称。
